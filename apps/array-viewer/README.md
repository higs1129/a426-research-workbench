# NumPy 数据查看器

一个离线、只读的中文桌面工具：打开 `.npz` / `.npy`，像变量查看器一样浏览数组名称、dtype、shape、估算内存和具体数值。只依赖现有 Python、Tkinter、NumPy、Pillow，无网络请求、后台服务、文件关联或注册表修改。

## 启动

Windows 双击 **`start_viewer.bat`**，再点「打开文件…」。也可将一个 NPZ / NPY 文件拖到这个 BAT 上；后者的资源管理器拖放操作尚未做人工验收。

在本应用目录运行：

```powershell
.\start_viewer.ps1
.\start_viewer.ps1 -File "D:\data\sample.npz"
.\start_viewer.ps1 -Python "C:\path\to\python.exe" -File "D:\data\sample.npy"
.\start_viewer.ps1 -Check
```

也可直接运行，跨平台时推荐此方式（本版只在 Windows 验证）：

```powershell
python -B viewer.py "D:\data\sample.npz"
```

解释器查找顺序：`-Python` → 环境变量 `ARRAY_VIEWER_PYTHON` → PATH 中的 `python.exe` → `py -3` → 用户目录内**已有的** Codex Python 缓存。显式指定解释器后若依赖不满足，会报错退出。不会自动安装软件、复制运行时或静默换用另一解释器。

依赖为 Python 3.10+、Tkinter、NumPy、Pillow（使用 Pillow 9.1+ 的 `Image.Resampling`）。Tkinter 通常随 Windows Python 安装。`-Check` 会检查依赖并实际创建、关闭一个 Tk 窗口。当前机器已有可用环境，无需安装额外包。

## 查看数据

1. 打开文件；也可在顶部输入完整路径后按 Enter。「Ctrl+O」调用文件选择器。
2. 在左侧选变量。标量显示单个值，一维数组显示为一列，二维数组按行列显示。
3. 三维及更高维选择「行轴」「列轴」，为剩余每个轴设置索引，然后「应用切片」。所有索引从 **0** 开始。界面持续显示原始索引表达式和当前轴顺序，允许显式交换行列轴。
4. 表格每页最多 **50 行 × 12 列**；箭头移动一页，也可填写「起始行」「起始列」后跳转。滚动条只滚动本页。浮点数约 8 位有效数字；点击单元格可在下方查看原始精度字符串，并选中复制。超长文本的表格预览最多 96 字符，单元格详情最多 4096 字符。
5. 「快速预览」显示一维曲线或当前二维切片热图。复数表格保留 `a+bj`；预览可选实部、虚部、幅值，复数默认幅值。NaN/Inf 保留在表格中，预览显示灰色或曲线断开。

如果文件有小型一维字符串数组 `columns`，且其长度匹配当前数组的**末轴**，界面会提供辅助标签；这只是基于字段名和长度的提示，不构造物理解释，不改变轴，也不拿坐标通道替换索引。

例如 `values.shape == (301, 401, 5)`：行轴 0、列轴 1、轴 2 索引 2，对应 `values[:, :, 2]`，显示 **301 行 × 401 列**。

## 数据读取与边界

- 文件只以 `rb` 打开。NPY 以 `np.memmap(..., mode="r")` 映射；NPZ 先读头部，选中后只把该数组解压到内存。没有磁盘解压缓存或导出文件，数组设为不可写。
- 不调用 pickle。NPY 头部经过限长和字面量解析，按验证后的 dtype/shape 读取数值字节；对象数组明确拒绝。标准整数、浮点、复数、布尔、字符串、日期/时间数组可查看；结构化 dtype、嵌套 dtype、原始 void 类型暂不支持。
- 默认上限：NPY 数据 **16 GiB**（只读映射），NPZ 文件 **512 MiB**，单个解压数组 **256 MiB**，压缩包 **1024 项** / **4 MiB** 目录，压缩比 **2000:1**，NPY 头部 **16 KiB**，维度 **32**，单个元素 **64 KiB**。超限会明确提示；不自动提高限制。内存数字是 dtype × 元素数的估算，不是整个进程内存。
- 不支持分卷、加密、ZIP64 大目录及非 stored/deflate 压缩包。损坏头部、大小不一致、重名数组会拒绝打开；未支持类型在变量列表标红。
- 文件目录扫描和加载在后台线程进行，窗口可关闭。正在加载时暂不切换文件/变量；不提供解压进度或中途取消按钮。关闭窗口会结束程序，没有常驻进程。
- 一维曲线最多 **2000 点**，热图最多 **512 × 512**，等间距抽样且保留两端。预览样本转为 float64 计算，不替代原始精度数据。界面显示原始尺寸和抽样尺寸；抽样可能遗漏窄峰，色阶只来自抽样的有限值。热图第 0 行在顶部，按索引拉伸，不表示真实物理坐标或几何比例。预览不是发表级图。
- 不提供编辑、保存或导出，不支持 MAT 文件。高维数组中若要固定的轴长度为 0，则不能取切片，会明确提示。读取期间请勿由其他程序替换或截断输入文件（尤其是正在内存映射的 NPY）。

## 验证

从仓库根目录，用满足依赖的 Python 执行：

```powershell
python -B -m unittest discover -s apps/array-viewer/tests -p test_array_data.py -v
python -B apps/array-viewer/tests/gui_smoke.py
python -B apps/array-viewer/tests/gui_smoke.py --real "D:\explicit\water_local.npz"
```

`gui_smoke.py` 实际创建 Tk 窗口并通过程序操作控件；它不替代视觉验收。真实样本参数是显式的只读输入，同时检查同目录存在的 `water_overview.npz`、`water_coreline.npz`。测试前后核对 SHA-256、大小和修改时间。所有生成夹具只在 `tests/artifacts/`（Git 忽略），不复制真实资料，不写输入目录。

2026-09-16 本机验收：

- 12 项数据测试通过，包含标量/一维/二维/空数组、四维所有行列轴组合、Fortran/大端存储、复数与非有限值、分页边界、NPY 1/2/3 格式、拒绝 pickle、畸形头部、压缩比和大小限制。
- Tk 程序交互测试通过，包含后台加载、分页、切片、表格、复数三种分量和热图。
- COMSOL `water_local` 的 `values[:, :, 2]` 与 NumPy `allow_pickle=False` 读取的整张参考切片一致，shape 为 `(301, 401)`。`water_overview` 和 `water_coreline` 逐数组一致；三个文件的哈希、大小、修改时间均未变。
- 真实桌面视觉验收已确认变量列表、第三轴通道选择、温升表格与热图、文件选择器打开及取消。文件选择器内选定文件并确认、资源管理器拖放，以及超大文件的实际压力测试尚未完成；轴交换、复数和分页由程序操作真实 Tk 控件验证。
