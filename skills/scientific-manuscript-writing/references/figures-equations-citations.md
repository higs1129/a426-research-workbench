# Figures, Equations, And Citations

## Figure Design

Assign each main figure:

- one scientific question;
- one visible comparison or evolution;
- one conclusion that can be stated without reading a long caption.

Within a multipanel figure, use a causal or evidentiary order. Common patterns include:

- system -> local mechanism -> observable;
- prediction -> parameter dependence -> experiment;
- weak-regime observable -> crossover -> complementary observable.

Use annotations to name variables, regimes, or extraction points. Put explanatory sentences in the caption or text. Avoid decorative color, unnecessary panels, and repeated summary maps.

For data figures:

- preserve raw-data provenance;
- distinguish data, fits, and theory visually;
- show uncertainty when repeated measurements or fitted uncertainty exist;
- do not fabricate error bars for single acquisitions;
- state when lines guide the eye rather than represent a model;
- verify final font, line width, axes, and legibility at publication size.

## Equation Selection

Keep an equation in the main text only if it does at least one of the following:

- defines the central physical quantity;
- exposes the mechanism or governing scale;
- maps the physical state to an observable;
- yields a prediction tested later;
- defines an extraction or calibration used on data.

Move lengthy derivations, implementation details, and algebraic expansions out of the main narrative unless the derivation itself is a contribution.

Immediately after an equation, explain:

1. what each new variable means;
2. which approximation or regime is used;
3. what physical conclusion follows;
4. where the expression is used later.

Do not present an intuitive approximation and a full numerical model as interchangeable. State the role of each and use one notation across both.

## Citation Practice

- Cite primary sources for original mechanisms and methods.
- Use reviews for broad field context, not priority claims.
- Place citations next to the exact supported statement.
- Record what conclusion each source supports; do not cite from title or abstract alone when a quantitative or mechanistic claim is made.
- Separate "has been demonstrated," "has been proposed," and "is commonly used."
- Compare related work by observable, regime, resource requirement, or limitation instead of vague superiority.

## Caption Practice

A caption should identify:

- what is plotted or depicted;
- the meaning of color, symbols, lines, and shaded regions;
- essential fixed parameters;
- whether curves are measured, fitted, calculated, or schematic;
- the extraction definition for non-obvious quantities.

The caption should support independent reading without reproducing the full Results paragraph.
