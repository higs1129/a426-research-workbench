# Skill 开发规则

本目录保存个人 Skill 的源码。目标是把已经在真实任务中重复出现、边界稳定的工作流沉淀成小而可靠的能力，而不是把所有项目经验都塞进一个巨大 Skill。

## 何时创建 Skill

满足以下条件再创建：

1. 工作至少重复出现过，或已有明确的下一次复用场景。
2. 输入、输出和完成标准可以说清楚。
3. 单靠项目 `AGENTS.md` 不能表达，且复用能减少操作或判断负担。

一次性研究背景、某个文件夹的路由、设备当前状态和临时项目决策应留在项目记录或项目 `AGENTS.md`，不升级成全局 Skill。

## 最小结构

```text
<skill-name>/
  SKILL.md
  agents/openai.yaml  仅用于 Codex 界面元数据
  references/      仅在确有较长参考资料时创建
  scripts/         仅在稳定机械操作值得自动化时创建
  assets/          仅保存交付所需模板或静态资源
```

不要预先创建空目录。新 Skill 可从 `_template/SKILL.md.template` 起步，但必须替换所有占位内容。

## SKILL.md 要求

- `name` 使用小写连字符命名，并与目录名一致。
- `name` 长度为 1–64 个字符，不以连字符开头或结尾，不使用连续连字符。
- `description` 使用第三人称，同时写清“做什么、何时使用、何时不使用”；触发行为主要依赖这里，长度不超过 1024 个字符。
- 顶层 frontmatter 只使用 `name`、`description`、`license`、`compatibility`、`allowed-tools` 和 `metadata`；额外信息放入 `metadata`。
- 每个 Skill 必须包含块状 YAML 的 `metadata.version` 和 `metadata.skill-author`；版本号必须为带引号的字符串。新 Skill 从 `"1.0"` 开始，普通改进升级次版本，破坏性重构升级主版本。
- `allowed-tools` 如需使用，写成空格分隔字符串，不写成 YAML 数组。只有真实环境依赖才写入 `compatibility`。
- 正文写必要的决策、步骤、边界和验证方法，不重复常识或堆叠背景。
- 正文优先组织为目的与边界、适用场景、可复现工作流、验证、失败模式和资源索引；简单 Skill 可省略没有实际内容的章节，不为了统一形式制造空段落。
- `SKILL.md` 保持在 500 行以内；较长模式、规范、示例和领域资料放入 `references/` 并按需路由。
- 多种工具都能完成时，说明优先级和降级路径。
- 引用相对路径时，以 Skill 目录为根。
- 用户明确要求应优先于 Skill 的默认偏好，但不能突破安全边界。

## 支持文件与测试

- `agents/openai.yaml` 是 Codex 专用扩展，保持与 `SKILL.md` 的名称、描述和默认提示一致；不要把它误当成跨平台 Agent Skills 的必需文件。
- `references/` 只保存会改变决策且需要按需读取的资料，并在 `SKILL.md` 中说明何时读取。
- `scripts/` 只承载重复、脆弱或需要确定性的逻辑；脚本必须有明确输入、输出、失败行为和最小测试。
- 测试、fixture、临时输出和生成缓存不放在 Skill 目录内；需要时放入仓库级 `tests/<skill-name>/`。
- 不在 Skill 中保存密钥、私人网址、未公开资料、硬编码本机绝对路径或与当前机器绑定的临时状态。

## 避免重复

- 新建前搜索现有 Skill 的描述和步骤。
- 两个 Skill 若输入、核心步骤和输出大体相同，应扩展已有 Skill，而不是复制一份改名。
- 只有触发场景、工具链或验收标准实质不同，才拆成不同 Skill。
- 跨 Skill 的通用长说明优先放公共参考文档；不要靠复制粘贴保持“独立”。

## 验证

每次修改至少完成：

1. 运行 Skill 结构校验。
2. 用一个应触发、一个不应触发的示例检查 `description`。
3. 对脚本运行最小可重复测试或 dry run。
4. 检查 frontmatter、相对链接、500 行限制、版本号和支持文件结构。
5. 检查没有硬编码密钥、个人临时路径、未公开资料或不可移植状态。
6. 记录真实使用反馈；只有源码版本通过验证后，才更新全局安装副本。

## 源码与安装副本

- 本目录是唯一维护入口和 Git 源码。
- `C:\Users\Administrator\.codex\skills\` 是运行时安装位置。
- 使用中发现问题时，回到本目录改源码、测试、提交，再更新安装副本。
- 不允许源码和安装副本分别演化；若发现差异，先比较并人工决定保留哪一版。
